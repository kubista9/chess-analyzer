- **`--asof` semantics** (`shared/window.ts`, used by `scripts/verify/_lib.ts`): `--asof YYYY-MM-DD` means end of that UTC day, inclusive, so `end = Date.parse(asof + "T23:59:59Z") / 1000`. `start = end - days * 86400`, also inclusive. A game counts when `start <= end_time <= end`. `WINDOW_DAYS = 183`, overridable with `--days N`. Invalid or impossible dates (e.g. 2026-02-30) throw. Without `--asof`, today's UTC date is used. Over the archive snapshot, `--asof 2026-09-26` reproduces the plan's golden window: 1,377 blitz+rapid standard games, 1,231 blitz, 685 as White.

## Deviations from the spec, and why

- **.env via config.ts only.** The dev:server and start scripts are unchanged: no `--env-file-if-exists` flags. The guarded `process.loadEnvFile` in config.ts covers the server, `npm start`, CLI and verify scripts with one mechanism, per the caller's instruction and the GLOBAL "load .env for CLI and verify scripts" item.
- **`__filename`/`__dirname` are gone, `fileURLToPath` stays.** The fileURLToPath import is kept to anchor rootDir (critic correction), and the unused `__filename`/`__dirname` locals are removed.
- **Shared base config.** The critic's "cleaner" option is used (`tsconfig.base.node.json`), rather than `tsconfig.test.json` extending the server config with `exclude: []`.
- **`vite.config.ts` moved** from the web tsconfig to `tsconfig.test.json`. Vite's types reference `@types/node`, so they made `node:fs` and Node globals legal in `src/` (verified: a `node:fs` import in src type-checked before the move and fails with TS2307 after). This goes slightly beyond the plan, and it closes the leak the critic described.
- **vitest ^5 instead of ^3.2**, and no src tests (critic corrections).
- **`loadArchiveMonths` is not implemented.** The raw-month on-disk format does not exist yet, and under the SQLite override the months live in `archive_months`. The P2 critic says to add it in P2, so `_lib.ts` has `loadRawGames` (the existing cache), the asof helpers and the table printer.
- **The window arithmetic lives in `shared/window.ts`**, not inside `_lib.ts`. That way it is unit-tested within the vitest scope (shared/ and server/ only), and the P2 server window can reuse it.
- **The warning text** is `WARNING: API exposed on LAN; no auth (HOST=<host>). Unset HOST to bind to 127.0.0.1 only.` It contains the spec's phrase.
